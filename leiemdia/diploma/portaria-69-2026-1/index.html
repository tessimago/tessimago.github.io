As instruções para preencher a declaração mensal de remunerações mudam para 2026. É necessário utilizar um novo código para os subsídios pagos a bombeiros voluntários e atualizar a descrição de outros tipos de rendimentos como prémios de produtividade.

  • Criação de novo código para compensações e subsídios a bombeiros voluntários
  • Alteração na descrição do código para prémios de produtividade e participações nos lucros
  • Novas regras de preenchimento da DMR para o ano de 2026
