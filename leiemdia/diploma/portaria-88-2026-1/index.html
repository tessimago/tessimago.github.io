Sumário oficial: Determina os valores dos coeficientes de revalorização a aplicar na atualização das remunerações anuais.

Ver diploma oficial → PDF oficial

Em português claro

Esta norma define os novos valores para atualizar as remunerações que servem de base ao cálculo de pensões de velhice e invalidez durante o ano de 2026. Para as carreiras contributivas após 2002, a atualização será de 2,70%, enquanto para as restantes situações o valor será de 2,20%.

  • Atualização de 2,70% para remunerações registadas a partir de 1 de janeiro de 2002.
  • Atualização de 2,20% para as demais situações de remunerações anuais.
  • Aplicação destes coeficientes para o cálculo de reembolsos e restituições de quotizações à Segurança Social.
  • Aplicação para a atualização de rendimentos do complemento solidário para idosos.
